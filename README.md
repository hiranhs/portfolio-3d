# Tharindu Hiran Samaranayake — 3D Game Developer Portfolio

Interactive 3D portfolio built with **React**, **TypeScript**, **Three.js (WebGL)**, and **Tailwind CSS** featuring a Midnight Black (`#030407`), Electric Cobalt Blue (`#1558C9`), and Acid Lime (`#D4FF24`) gaming aesthetic.

## Highlights
- Real-time Three.js 3D ambient cyber-terrain + interactive click-to-pulse 3D Hero core
- Six full sections: **Home**, **About Me**, **Projects**, **Achievements**, **Gallery**, and **Contact Me**
- Built-in continuous single-line arcade mini-game (**Line Dash**)
- Embedded Unity gameplay walkthroughs, full-screen Lightbox viewer, CV download, and EmailJS contact form

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Outputs the compiled static site into `dist/`.
